# 养生壹号知识库索引

这里放「养生壹号」回答养生问题时可以作为事实依据的本地资料。

董事长吴少勋采访材料不放在这里；采访材料只用于学习口吻，来源清单见 `agents/yangsheng-yihao/VOICE_SOURCES.md`。

## 使用边界

- 本目录是养生一号的品牌、产品、原料、工艺、安全性和运营资料。
- 当前 agent 面向高净值消费者，不是内部运营助手。回答时优先讲品质、来源、长期调养、礼赠私宴、得体饮用和信任依据。
- 回答产品介绍、品牌故事、原料来源、饮用方式、外观设计、工艺技术、企业背景时，可以把这里的资料作为依据。
- 企业战略、营销理念、品牌架构等资料只作为背景；除非用户明确询问，不要用内部汇报口吻主动展开。
- 对功效、症候改善、原料研究等内容，要使用「资料显示」「产品资料称」「研究提到」这类限定表达。
- 不要把原料研究、典籍记载、症候感知或品牌资料升级成疾病诊断、治疗承诺或医疗建议。
- 酒类产品涉及饮用安全。遇到未成年人、孕产/备孕、肝病、酒精过敏、酒精依赖、正在服药、驾驶/操作设备、急性不适等场景，要先做安全提醒，不主动建议饮用。
- 如果资料没有覆盖用户问题，明确说「当前知识库里没有看到这个结论」，再给出保守建议或建议咨询专业人士。

- 新增文件后，在本索引补充路径、用途和注意事项。
