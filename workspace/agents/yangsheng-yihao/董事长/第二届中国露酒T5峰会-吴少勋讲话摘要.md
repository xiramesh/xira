# 第二届中国露酒T5峰会\-吴少勋讲话摘要

**第二届中国露酒T5峰会**

吴少勋讲话摘要 2023年



　会上，劲牌有限公司董事长吴少勋从劲牌公司的营销工作、产品研发、用户运维三个方面出发，分析了露酒行业的发展瓶颈问题，同时也表达出对露酒行业未来的信心。

**以下为讲话摘要：**

1. **关于露酒行业的发展瓶颈问题**

　　露酒行业确实遇到了瓶颈，这是一个现实问题，也发生在劲牌身上。劲牌2017年过了百亿，在茅台、\(82\.350, \-0\.36, \-0\.44%）、洋河之后位列第四，但不到十年时间，五粮液业绩七八百亿，汾酒、\(87\.550, \-0\.95, \-1\.07%）今年都过300亿了。刚才，段总说他们遇到了困难，我们一样。去年劲牌才恢复到2019年的水平，等于说这么多年，我们一直停滞不前。

　　当初在我们后面汾酒、泸州老窖等等才几十个亿，现在我们跟他们比完全不在一个数量级上，这充分说明露酒还是遇到了很大困难的。

**二、关于对露酒行业未来的信心**

　　我给大家报告下劲牌最近这些年的工作，跟大家做个交流，实际上我们进行了一些探索。

　　首先，露酒行业是大有前途的，我是充满希望的，劲牌肯定不会放弃，更不会想着去做其他的，这条路我们一定会坚持走下去。

　　去年我们公司做了一个20年的规划，今年在做30年规划，因为今年是劲牌成立70年，30年规划就是到公司一百年的时候，除了持正堂药业是为了提高和保障露酒的产品力外，我们的规划中全部是围绕露酒这个行业来做工作，没有其他的业务。

　　去年提出20年规划，到2042年，计划销售额过800亿，相当于五粮液今年的水平。到2053年，我想一千亿应该是没有问题的，我们不是说空话，我们做了很多分析和提前的准备。比如劲牌的产能有十几万吨，恐怕在中国酒业很少有企业有这么大的产能，存量超过了几十万吨，我估计比五粮液、汾酒、泸州老窖存酒都要多。我们这么大的产能和存量，但是没有转化为业绩。

　　我知道五粮液产能大概10万吨左右，去年存酒17万吨，但做到了700多亿，销售额是我们的很多倍，说明我们问题不小。所以根据我们的规划，我们经过20年、30年，然后沿着我们现在这条差异化的路线走下去，我相信20年、30年的目标肯定是可以实现的。

　　倘若我们有五粮液、汾酒、泸州老窖现在的品牌力和营销力，根据我们的现有资源，那我们现在都可以过1千亿，当然这么说是给我们自己建立信心，毕竟我们还没有这个品牌力和营销力。

　　其次，劲牌还是看到了希望，大家也可以拭目以待。比如说今年肯定比去年好，明年肯定比今年好，这一点我们是做了充分的研判和努力的，可能未来十年，二十年会保持在10个点左右的增长。

**三、关于公司营销存在的核心问题**

　　最近我们在总结反思，内部在进行研讨时总结我们存在两个突出的问题。

　　第一，尽管我们业绩下降或者停滞不前，但是我们还是做了很多努力，也一直在反思，为什么我们那么努力，那么拼，最后是事倍功半，劳而不功。最近这几年，我们基本上是白\+黑，5\+2，每天7点钟开早会，开到8点。星期六、星期天其中有一天也在开会找问题，但这么努力没有业绩。

　　一是品类打造问题，这是一个很关键的问题。白酒是一个品类，露酒尽管过去是等同于配制酒或者保健酒，但消费者对这个品类没有广泛的认知、认同。没有品类认知就没有品牌，所以我们做了很多工作不仅仅是事倍功半的问题，搞不好是劳而无功，因为没有消费者基础，这是我们的一个痛点，我希望我们大家一起努力，特别在我们酒协的领导下，怎么把露酒的品类做起来，然后打造品牌力。可能品类建立和品牌打造是可以同时进行的。

　　第二，过去我们的工作方向搞错了。比如在产品定位方面，我们想鱼和熊掌兼得，保健酒又想有保健功能，又想能够满足社交畅饮需求，什么场景都想要，什么人都想捞，为此我们还开发了一个金标劲酒，想通过这个产品来实现保健酒的升级，但没有成功，金标劲酒价格是中国劲酒的三倍。但作为消费者，凭什么花那么多钱去购买它，我有社交需求，要畅饮，可以选择的白酒很多，为什么要喝保健酒。

　　所以公司类别把我们的产品分为两类保健酒和草本白酒。其中保健酒我们回归功能属性，而且限量饮用。比如养生1号，单次饮用最多不超过一两、中国劲酒不超过二两半等等。每一个品种我们都做了充分的测试验证，确定了最佳饮用量，并且指导用户饮用，不能像过去一样搞畅饮。

　　“劲牌虽好，可不要贪杯”，实际上是出自我之口。保健酒喝多了以后确实难受，大白天的可能满眼都是星星，几天缓不过来，但白酒喝了之后可能睡一觉就醒了。但保健酒不能畅饮，必须限量饮用。短期看多喝点对企业而言销量提升了，但保健酒一旦喝多了把用户伤害了，可能一辈子都不喝了。

　　那社交型的酒怎么解决，我们内部叫草本白酒，过去我们把它与保健酒混为一谈，实践证明这个是不行的。保健酒一定要回归功能属性，而且每个产品的功能定位要差异化，不能搞泛功能，否则价格、价值就没办法体现。比如养生1号功能定位是固本培元，中国劲酒是免疫调节、抗疲劳。我们还有改善睡眠的金眠酒，舒经活络、抗风湿的追风酒，还正在开发改善前列腺等功能的保健酒，这些产品一方面通过功能定位，然后通过基酒年份、原料价值、工艺等来做差异化的价值区隔。

　　最近这些年我们把产品定位基本搞清楚、弄明白了。我是1987年6月1日来劲牌做厂长、书记的，今年已经37年了。最近这几年通过大家的努力，把保健酒和草本白酒的定位理顺。当然现在我们的产品战略选择未必是最好的选择，大家都可以去探索，另外对我们的做法可以加以指导。

　　刚刚提到的保健酒必须有功能，而且要真实可信。另外草本白酒我们主要围绕三高痛点来做，饮酒人群三高是一个很大的痛点。饮酒本身也有这个痛点，另外还有饮酒对消化道、神经的影响。比如对脂肪肝的影响，昨天晚上我们喝的草本白酒基本解决了脂肪肝的问题，就是喝其他白酒喝半斤，喝我们的也是半斤，相比较肯定有明显的优势，这个是得到了科学证明的。另外对血糖有一定的改善，但血压问题、消化道问题没有解决。关于酒对神经的伤害我们看到有些人端杯子的时候手会发抖，另外有的不喝酒晚上睡不着觉，就是成瘾，我身边有很多人这样的人，所以怎么样把酒做到对神经伤害最小，由于社交需要，经常会一醉方休，长期过量饮酒会积酒成疾，对神经的影响在部分解决，我们在验证中。

　　草本白酒除了解决这些痛点外，我们通过年份来区分价值，比如我们的草本年份酒是宋理事长他们主导的第一个双认证的，拿到了00001认证证书，另外，我们的真年份标注的是最低年份，标准的要求是可以加权平均的。

**四、关于公司产品研发投入情况**

　　公司围绕我们的产品分类，在研发上我们应该是进行了大量的投入。

　　我们公司提出“按做药的标准来做酒”，我们确实按这个要求在做，比如说，我们研究院有一个药理研究室，常年都在进行研究。同时，我们与外面合作单位也很多，国内外跟我们合作的主要是药和医学方面的研究，跟酿酒相关的合作单位也有，但可能占比只有1/5左右。为什么会这样安排，因为我们的产品都是差异化的，比如保健酒的功能及作用机理，草本白酒怎么降低酒对身体的伤害，一定要讲科学，所以要进行大量的投入，并且没人做，没有现成成果可以应用，我们是开辟南海，我们每年的投入约3亿在产品研发方面。

**五、关于用户运维工作**

　　在用户运维上我们过去也是有教训的，比如中国劲酒，到现在为止还没有回到历史的最好水平，有的市场已经到了，有的市场还有很大的差距。我们的中国劲酒历史最好水平酒体销量十几万吨，现在才过10万吨，在恢复性增长。为什么出现这个问题，根本的原因是我们洞察力出了问题。具体点就是我们不知道谁在喝我们的酒，在哪里喝，为什么要喝。所以不明不白地把用户弄丢了，2017年达到了历史最好水平，但2020年出现了负增长，尽管有疫情的因素，但更多的是我们自己出了问题，其间我们做了很多工作，也叠加了很多动作，但都是围绕渠道来做工作，最后终于是山穷水尽了。

　　实际上根本原因是我们没有抓住用户，不知道谁在喝，在哪里喝，为什么喝。当然，现在我们是B端\+C端，首先把喝我们产品的人找到，然后针对性地去做工作，跟他们沟通互动。

　　我们品种多，养生1号和中国劲酒价格相差二三十倍，人群完全不一样，找到后还要想着怎么跟他们对话，用什么话术，白酒做起来相对简单，但露酒做起来很难。白酒可以通过香型来进行区别，但保健酒不一样，我们要讲功能，比如说我们某一款产品到底能给消费者带来什么样的功能体验，值多少钱，有什么利益点等等都需要去跟用户沟通交流，并且让他们相信，能正在解决用户痛点，所以这个工作很难。

**六、关于会议组织形式建议及露酒行业发展希望**

　　由于时间关系，总体上我们还有很多问题需要进一步讨论。我建议以后的会议形式做些调整，应该是讨论式的，而不是发言式的，白酒的一些会议这种形式可以，倘若这种会议形式我不知道会是一个什么样的会议效果，露酒行业还有很多问题，还没有找到解决方案。椰岛段总刚刚发言的感慨，我也是有这种感慨。想当初，2000年左右露酒行业有椰岛鹿龟酒、致中和、劲牌三巨头。20多年过去了，他们两个都不知道跑哪里去了，我一直认为露酒行业应该是百花齐放，大家要红一片，不能劲牌一个人红。孤独对我们来说未必是一件好事。露酒现在还是荒漠，我们要做成森林，要良性循环，劲牌不能仅仅是荒漠中的一棵树、一根草，否则东南西北风我们都要经受着，这对我们不是好事，最后可能被消灭了。我希望我们能把露酒行业蛋糕做大，哪怕我们只是其中的一块，相对份额小了，但绝对份额大。劲牌愿意跟大家一起努力把露酒行业蛋糕做大！
