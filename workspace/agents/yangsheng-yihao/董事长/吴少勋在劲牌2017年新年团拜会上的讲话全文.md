# 吴少勋在劲牌2017年新年团拜会上的讲话全文

**吴少勋在劲牌2017年新年团拜会上的讲话全文**





我们到底要什么。

今天，我来谈一个问题，我们到底要什么？这实际上是一个禅问，是每一个人一生一世，一个组织、一个国家从诞生到消亡，都在有意无意、不断回答的问题，也是必须回答的问题。尽管这个问题没有标准答案，而且还此一时彼一时，但所有人都在用行动回答着。

我记得我是在1987年6月1日来这里做厂长书记的，在座的还有不少见证人，在那个时候我们要什么呢？就是活着，能够活下来。然后就是想达到1985年的水平，我公司87年之前的鼎盛时期就是85年，那时销售额接近500万，利税140多万。后来那个水平也达到了，以后就是1000万的追求了，再以后不断加码，直到现在。

去年我们的销售额是92亿多一点，今年如果过不了百亿的话，明年不出意外这个百亿的目标就是囊中之物了。那100亿过后我们又会有什么企图呢？我想我们都知道，除了啤酒、红酒以外，我们处于其他所有酒类的第四，处在洋河之后。我们过了百亿，下个目标就是洋河了？洋河2016年销售额160多个亿，那肯定就是我们的目标了。按这个逻辑，倘若有朝一日我们超过了洋河，那再下一个目标呢？五粮液？五粮液现在是两百多亿。那再下一个呢？毋庸置疑就是茅台了。我相信我们在座的同志，尤其是营销的同志，有这么一个所谓的梦，甚至我自己有时候也在暗暗地较劲，把这个作为毕生的追求。你说这错了吗？按惯性思维也没错到哪里去。你说对吗？按生存哲学恐怕要打个问号。这使得我们必须回答我们到底要什么的问题。

有时候一个销售目标或者一个行业地位的追求，是不是我们所要的一个结果？我认为不尽然。这实际上是生存与发展的问题。

比如说，目标的不断提高，即所谓的发展，具体到我们当前的实际，就是GDP增长、销售额提高。生存和发展有时是相辅相成的，在某种情况下，没有发展，你的生存也很困难。按兵法上说，进攻是最好的防守，而发展，就是进攻。

但有时候它们又是矛盾的，这矛盾甚至还会很大。可能阶段性增长的目标达到了，但可能为你的生存埋下了祸根，结果可能是灾难性的。

改革开放三十多年，中国有很多企业不存在了，在我们身边，有很多企业现在苦撑着，恐怕离死亡也不远了。那问题出在哪里呢？我认为就是发展和生存这个矛盾没有处理好，有的想通过增长、发展去解决和掩饰一些矛盾，结果适得其反。很多企业不是做小做死的，而是做大做死的。所以，度的掌握、增长欲望的控制，对我们来说是一个挑战和考验。

我们的百年企业、百年品牌、百年市场，跟我们的发展增长有没有关系？有。但是否必须增长才能实现百年目标？不一定。具体到我们的实践，可以证明这一点。比如我们劲酒在很多市场就出现了这些问题，为了保增长，采取一些不切实际的方法和手段，短时间内销售上去了，矛盾被掩盖，但后果呢？兜不住了。这些现象倘若不加以遏制，结果可想而知。

在有的情况下，我们的发展和增长不一定是好事。本来我们工作的目的都是想自己过个好日子，但有时候恰恰相反。企业发展了，市场增长了，一些设定的目标达成了，自己却不愉快、不幸福了。每天如同惊弓之鸟，终日处于水深火热之中。

这不是简单的问题，这本身就是一种失败，而且是一个企业走向衰败的前兆。因为人在这种状态下长期工作，迟早是要崩溃的。在我们身

边也有这种情况，一些老板、企业家，他们的事业倒是做大了，生活质量却下降了，这是他们想要的吗？

我们要愉快地工作着，幸福地生活着，这跟我们的百年企业、百年品牌、百年时常是相对应的，如果仅仅只有其一，没有其二的话，就没有意义了。

当然，这是一个很大的话题，是需要劲牌人在新的一年里展开大讨论的一个问题。这个问题，我也有答案，但不适宜每个人。仅仅我回答，是不够的，必须大家一起来回答，而且回答必须是相对正确的。不然我就不知道我们企业的未来是个什么样子。

现在我们一谈微增长、不增长、负增长，我们有些同志就满腹狐疑，我们干什么呢？我们的市场不增长了，我们的工作是不是可以不努力了？那绝对不是。尽管市场可能是微增长，甚至不增长、负增长，但我们的努力还要加倍。因为大家都知道，逆水行舟，不进则退。

刚才有同志在早会发言中说了，竞争越来越激烈，矛盾越来越尖锐，问题越来越复杂。这些矛盾和问题如不加以解决，将直接影响到企业的生存发展。

还是回到要什么的问题。我们发展的目的，如果是为了好好地活着，为了我们的百年目标，那么有时候，它就不需要大幅增长。最近这些年我提得比较多的是，我们要接受和适应新常态。我觉得领导提出这个“新常态”绝不是开玩笑，而是经过深思熟虑。实际上我们往往依然沉浸在过去的发展观上，没有进入新常态，总感觉不增长就没有面子，价值得不到实现。这点在营销方面表现得特别突出。有些区域总监和营销经理甚至有一种失落感，因为过去都是一路高歌，现在的市场却只能维持，有的甚至还在下降，于是深感挫败。正是这些情绪的存在和蔓延，才使得“我们到底要什么”这一问题，必须思考和回答。

一般的逻辑好像就是企业越做大越好做，恐怕我们在座的有些同志也有这种心态，觉得劲牌按道理应当是越来越强大、越来越所向无敌，但实际情况却并非如此。

我过去经常讲到登山的道理——我们企业倘若今年或明年达到100亿的目标，那说明我们到了一个高度了，在这个高度上，其实是越发困难的。在座各位都登过山，或许山大小不一、高低不同，但无论怎样，都是越往上走，难度越大。

做企业亦如是。不是大到一定程度就好像有了一台永动机，像王健林先生说的“先定一个能达到的小目标，比方说我先挣它一个亿”那么轻松。所以我们一定要有充分的认识，别把一切看得太简单，否则，我们离“下山”就不远了。

“我们到底要什么”是我们今天和未来都要不断探讨和回答的问题，我希望在此与诸位达成共识，这共识或许就像刚才有同志说的，“健康可持续”，这才是我们需要的。

健康长寿，是我们每个组织乃至每个人的共同追求。我们不仅要学会工作，更要学会思考。思考，是我们的软实力。通过深刻的思考去调整我们的语言和行动；通过工作再去调整我们的一些思考，使我们的方向更明确一点，目标更清晰一点，路子走得更稳一点，我们公司的未来更美好一点，我们的生活、工作更愉快、更幸福一点！
